Un número es tramposo si cumple las tres condiciones al mismo tiempo:

Es par

NO es múltiplo de 4

La suma de sus dígitos es impar


INICIO

  LEER n

  // 1. Calcular suma de dígitos
  suma = 0
  temp = n

  MIENTRAS temp > 0 HACER
      digito = temp MOD 10
      suma = suma + digito
      temp = temp DIV 10
  FIN MIENTRAS

  // 2. Verificar condiciones
  esPar = (n MOD 2 = 0)
  esMultiplo4 = (n MOD 4 = 0)
  sumaImpar = (suma MOD 2 ≠ 0)

  SI esPar Y NO esMultiplo4 Y sumaImpar ENTONCES
      ESCRIBIR "Número tramposo"
  SINO
      ESCRIBIR "Número normal"
  FIN SI

FIN

Tienes una pizza circular. Con solo 3 cortes rectos (de lado a lado), ¿cuál es el máximo número de porciones que puedes obtener?



ALGORITMO maximoPorcionesPizza(numeroCortes)
    
    porciones = 1
    
    PARA corte = 1 HASTA numeroCortes HACER
        // Cada nuevo corte intersecta todos los anteriores
        porciones = porciones + corte
    FIN PARA
    
    RETORNAR porciones
    
FIN ALGORITMO

// Para 3 cortes:
INICIO
    porciones = 1
    
    // Corte 1
    porciones = 1 + 1 = 2
    
    // Corte 2 (intersecta el corte 1)
    porciones = 2 + 2 = 4
    
    // Corte 3 (intersecta cortes 1 y 2)
    porciones = 4 + 3 = 7
    
    MOSTRAR "Máximo de porciones: 7"
FIN
